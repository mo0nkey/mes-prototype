# MES 演示原型系统 · 角色权限与审核流程设计

> 版本：v0.1（基于需求方实际组织架构细化）
> 上游：《SRS v0.2》《概要设计 v0.2》（本设计是对 §3 角色与 §4 流程的细化，含两项重大流程调整）
> 说明：本设计引入 **组织树 + 三级层级** 的角色模型、**逐级审核流转**机制、**模拟排期**流程

---

## 1. 组织架构（需求方实际）

```
厂长
├── 办公室（每科 3 级：科长 / 组长 / 成员）
│   ├── 项目科  ⭐ 启动会定计划，不向上提交
│   ├── 仓库科    进料 / 发料 / 发货
│   ├── 计划科    排产 / 交期
│   ├── 设计科    产品设计 / 工艺 / BOM
│   ├── 编程科    CNC 加工程序
│   └── 综合科    固定资产等台账
├── 厂房
│   ├── 车间主任  ★ 电脑确认 + 线下管控厂房内所有工作
│   ├── CNC 组
│   ├── 钳工组
│   └── 装配组
└── 质量科（独立于厂内 · 常驻监督）→ 第一期只读
```

### 1.1 关键规则
- **汇报机制**：除项目科外，各科成员的工作**提交确认给上一级**（成员→组长→科长），**科长审核通过后转给下一个环节/工种**；
- **厂房机制**：CNC / 钳工 / 装配 每道工序完成后，由**车间主任在电脑上确认**后流转下一个工种；
- **项目科特例**：项目启动通过**线下启动会**拉相关人员确认产品计划，系统内**排期采用"模拟"功能**——模拟结果在线上会议演示，确认后才转为正式排期，之后跟踪项目进度；
- **质量科**：独立监督，第一期只读（看板 + 追溯），为二期质检预留。

## 2. 完整业务流转链（对应"下一个工种"）

```text
① 项目科（启动会→项目建档）
   │
② 仓库科·进料（原料批次入库 + 贴条码）★追溯起点
   │
③ 计划科（创建工单 → 模拟排期 → 线上演示 → 确认发布 → 派工）
   │
④ 设计科（模具设计 → 工艺路线 / BOM）→ 科长审核
   │
⑤ 编程科（CNC 程序编制）→ 科长审核
   │
⑥ CNC 加工（工位执行：开工/报工）→ 车间主任确认
   │
⑦ 钳工（研配/精修）→ 车间主任确认
   │
⑧ 装配（装配/合模）→ 车间主任确认 → 工单完工
   │
⑨ 仓库科·发货（成品出库记录）
   │
⑩ 综合科（固定资产等台账，独立模块）
```

> 每步流转都依赖上一环节"提交确认 + 上级审核通过"，审核记录全量留痕（谁、何时、结果）。

## 3. 角色与权限模型

### 3.1 角色清单（组织 × 层级）

| 角色 | 组织归属 | 层级 | 系统职责 |
|---|---|---|---|
| 厂长 | 厂部 | - | 全局只读：看板 / 报表 / 交期风险 |
| 项目科长 / 组长 / 成员 | 办公室·项目科 | 3 级 | 项目台账、进度跟踪；排期模拟演示 |
| 仓库科长 / 组长 / 成员 | 办公室·仓库科 | 3 级 | 进料批次入库、发料、发货出库 |
| 计划科长 / 组长 / 成员 | 办公室·计划科 | 3 级 | 工单、模拟/正式排产、交期监控 |
| 设计科长 / 组长 / 成员 | 办公室·设计科 | 3 级 | 产品/工艺/BOM 维护；科长审核设计成果 |
| 编程科长 / 组长 / 成员 | 办公室·编程科 | 3 级 | CNC 程序维护；科长审核程序 |
| 综合科长 / 组长 / 成员 | 办公室·综合科 | 3 级 | 资产台账（独立简单模块） |
| 车间主任 | 厂房 | - | **确认厂房内所有工序流转** + 线下管控 |
| CNC 操作工 | 厂房·CNC | 成员 | 工位执行：开工 / 报工 / 提交确认 |
| 钳工 | 厂房·钳工 | 成员 | 同上 |
| 装配工 | 厂房·装配 | 成员 | 同上 |

## 4. 重大流程调整（相对设计 v0.2）

### 4.1 排产流程：增加"模拟排期"环节 ★
原：排产直接发布派工。
新：**模拟排期（草稿）→ 线上会议演示 → 计划员/项目科确认 → 转为正式排期 → 派工**。
- 模拟排期不占用正式产能、不派工；
- 演示时支持多人查看（演示模式）；
- 确认发布后生成正式排产计划（进入原倒排/预警/调整逻辑的后续）。

### 4.2 报工/流转流程：增加"提交审核"环节 ★
原：报工完成 → 自动流转下一工序。
新：**操作工报工 → 提交确认 → 上级审核（科室工作由科长、厂房工序由车间主任）→ 审核通过 → 流转下一工序/工种；审核驳回 → 退回修改**。
- 报工记录增加状态：待审核 / 已通过 / 已驳回；
- 审核驳回需填写原因，留痕。

### 4.3 工单状态机：增加"待审核"语义
原：生产中 → 完工。
新：生产中（工序级流转，每工序含 提交→审核 子流程）→ 末道工序审核通过 → 完工。

## 6. 演示场景更新（并入 SRS §5）

新增演示场景 9：**跨环节审核流转**
项目建档 → 进料 → 模拟排期并演示 → 确认发布 → 设计审核 → 编程审核 → CNC 开工/报工 → 车间主任确认 → 钳工 → 确认 → 装配 → 确认 → 完工 → 发货。
每个环节演示"提交确认 → 上级审核 → 流转"闭环与留痕。
