## 1. 技术栈（最终确认）

| 层 | 选型 | 版本要求 |
|---|---|---|
| 后端 | **Python FastAPI** + SQLAlchemy 2 + Pydantic 2 | Python 3.12（用 uv 安装） |
| 数据库 | **SQLite**（WAL 模式，单文件零安装） | 内置 |
| 前端 | **Vue 3** + Element Plus + Vite + ECharts + Pinia | Node 24（已具备） |
| 环境 | **uv** 管理 Python 虚拟环境与依赖 | uv 0.12（已具备） |
| 认证 | JWT + RBAC（角色 = 组织 × 层级 × 权限集） | 自研轻量 |

## 3. 数据库：23 张核心表

| 分组 | 表 |
|---|---|
| 系统权限 | users、departments、roles、role_permissions、operation_logs |
| 主数据 | products（模具）、steel_specs（铁板规格）、materials（外购件）、process_routes、process_route_steps、mold_bom_items、machined_parts、machining_groups、material_batches、sn_rules |
| 项目/采购 | projects、purchase_requests、purchased_parts_inventory |

| 执行/追溯 | work_reports、review_records、batch_bindings、andon_events |

> 建表脚本在搭脚手架时随第一个可运行版本交付（DDL 由 SQLAlchemy 自动生成 + 种子数据填充）。

## 4. 启动方式（演示/开发）

```bash
# 1. 安装 Python 3.12（只需一次）
uv python install 3.12

# 2. 后端：安装依赖并启动（端口 8000）
cd backend
uv sync                        # 按 pyproject.toml 安装依赖
uv run fastapi dev app/main.py # 或 uv run uvicorn app.main:app --reload

# 3. 前端：安装依赖并启动（端口 5173）
cd frontend
npm install
npm run dev

# 4. 浏览器打开 http://localhost:5173
#    演示账号：admin / planner / proj01 / design01 / prog01 / wh01 / director(车间主任) / op01…
```

> 局域网演示：同一 WiFi 下其他电脑访问 `http://<本机IP>:5173`。

## 5. 首个可运行的最小闭环（脚手架目标，W2-W3）

1. 项目骨架（前后端目录、uv/npm 初始化、Vite 代理）；
2. SQLite 建库 + 23 表 + **种子数据**（6 套模具、铁板规格、部件 BOM、加工组、批次、演示账号）；
3. 登录 + JWT + **角色权限**（页面级路由守卫 + 操作级 v-perm 指令）；
4. 主数据页面（产品/BOM/工艺查看）；
5. **创建工单** → 列表展示（交期风险标记）。

> 跑通后立即演示，之后按里程碑：排产（W4-6）→ 执行/审核/追溯（W7-9）→ 看板/报表（W10-11）→ 八场景验收（W12）。

## 6. 排产算法实现要点（映射 04 文档）

- `services/scheduling.py` 实现：倒排主循环、最晚窗口贪心、逾期判定、手动调整重算；
- CNC 工时 = Σ 加工组工时（05 文档 §4.3），加工组规则做成**可配置分组类型字段**；
- 模拟排期（status=模拟）不占产能，确认发布后占用。

---

## 7. 权限实现要点（映射 03 文档）

- 登录返回：用户 → 组织（dept）+ 层级（level）+ 功能权限集（页面+按钮）；
- 前端：路由守卫（页面级）+ `v-perm` 指令（按钮级）+ 数据范围过滤（层级可见）；
- 后端：依赖注入校验权限 + 数据范围（成员→自己、组长→组、科长→科、厂长→全部）。
