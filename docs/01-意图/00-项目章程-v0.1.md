# MES 演示原型系统 · 项目章程

> 版本：v0.1 · 1 页纸基线（立项信息统一入口）
> 编制：产品经理视角 · 评审确认后作为项目基线

---

## 一、项目基本信息

| 项 | 内容 |
|---|---|
| 项目名称 | MES 演示原型系统（汽车零部件模具制造） |
| 项目性质 | **学习/演练 + 演示用途**（不落地生产，但按真实标准设计） |
| 周期 | 12 周（3 个月以内） |
| 交付物 | 单机可运行、浏览器可演示的 MES 原型 + 全套文档 |

## 二、目标与成功标准

| 目标 | 衡量方式 |
|---|---|
| 理解 MES 搭建全流程 | 走通 需求→设计→开发→测试→验收 全生命周期 |
| 演示核心闭环 | **取消纸质流转卡/工票，全部线上流转**（SRS §5 八场景） |
| 覆盖真实业务 | 多层级 BOM、逐级审核、模拟排期、交期预警、SN 追溯 |

## 三、范围

**第一期（MVP）做：** 主数据（产品/BOM/工艺/铁板/部件/加工组·种子数据）/ 项目台账 / 工单 / 模拟排期与正式排产 / 工位执行（开工·绑定·报工·提交审核）/ 审核工作台 / 齐套检查 / 追溯 / 看板 / 报表 / 角色权限 / 安灯。

**明确不做（第一期）：** 质检流程（角色预留只读）、设备数采、WMS/库存全流程、自动排产 APS、考勤、移动端、综合科资产页面（角色预留）。

## 四、干系人

| 角色 | 关注点 | 参与方式 |
|---|---|---|
| 需求方（厂长视角） | 全局看板、交期、组织权限 | 需求与验收决策 |
| 业务代表（车间/科室） | 流程可用性 | 需求澄清、演示反馈 |
| 演示对象（客户/同事） | 系统效果 | 里程碑演示 |
| 系统管理员（IT） | 部署运维 | 脚手架阶段介入 |

## 五、关键约束与风险

| 类型 | 内容 | 应对 |
|---|---|---|
| 时间 | 3 个月 | 按里程碑交付可演示版本 |
| 范围 | 范围蔓延 | 本章程 + SRS 为基线，变更走文档更新 |
| 领域 | 加工组规则未定 | 可配置占位 + feature flag（文档 05/07） |
| 环境 | Python 3.8 系统自带偏旧 | uv 安装 3.12 |

## 六、验收标准（总）

SRS §5 八个演示场景全流程走通 + 权限矩阵生效 + 追溯正反查询正确 + 文档与代码版本对齐。
