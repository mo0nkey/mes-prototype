# MES 演示原型系统 · 数据字典（23 表字段级）

> 版本：v0.1（对应概要设计 v0.2 §2 + 多层级模型 05 §8）
> 类型约定：INT=整数，TXT=文本，DEC=小数，DATETIME=时间，BOOL=布尔，ENUM=枚举
> 标记：🔑 主键 / ⭐ 追溯相关 / ★审核相关

---

## 一、系统与权限（5 表）

### 1. departments（组织部门树）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT 🔑 | 部门 ID |
| name | TXT | 部门名（厂长/项目科/仓库科/计划科/设计科/编程科/综合科/厂房/质量科） |
| parent_id | INT | 上级部门（树形结构） |
| kind | ENUM | office（办公室）/ factory（厂房）/ quality（质量）/ top（厂部） |

### 2. users（用户）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT 🔑 | 用户 ID |
| username | TXT | 登录名（唯一） |
| password_hash | TXT | 密码哈希（bcrypt） |
| real_name | TXT | 姓名 |
| dept_id | INT | 所属部门（外键 departments） |
| level | ENUM | chief（科长）/ leader（组长）/ member（成员）/ none（无层级） |
| position | ENUM | 岗位：designer/programmer/cnc/fitter/assembler/planner/warehouse/project/quality/director/admin |
| station_id | INT | 绑定工位（操作工） |
| active | BOOL | 是否启用 |

### 3. roles（角色）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT 🔑 | 角色 ID |
| code | TXT | 角色编码（如 PROJ_CHIEF、CNC_OP） |
| name | TXT | 角色名 |
| perm_json | TXT | 功能权限集（页面+按钮，JSON） |

### 4. role_permissions（角色-权限明细，可选冗余）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT 🔑 | ID |
| role_id | INT | 角色 |
| page | TXT | 页面编码（如 wo、scheduling） |
| action | TXT | 操作（view/create/edit/review/export…） |

### 5. operation_logs（操作日志）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT 🔑 | ID |
| user_id | INT | 操作人 |
| action | TXT | 动作描述 |
| target_type | TXT | 对象类型（工单/排产/审核…） |
| target_id | INT | 对象 ID |
| detail | TXT | 详情（含驳回原因等） |
| created_at | DATETIME | 时间 |

## 二、主数据（10 表）

### 6. products（模具产品）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT 🔑 | 产品 ID |
| code | TXT | 模具编码（MOLD-1001） |
| name | TXT | 名称（前门内板拉延模…） |
| spec | TXT | 规格说明 |
| standard_cycle_days | INT | 标准生产周期（天） |
| sn_rule_id | INT | SN 规则外键 |
| status | ENUM | active/retired |

### 7. steel_specs（铁板规格字典）⭐
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT 🔑 | 规格 ID |
| code | TXT | 规格型号（S-12-2000×1000） |
| thickness_mm | DEC | 厚度（mm） |
| width_x_length | TXT | 尺寸（如 2000×1000） |
| grade | TXT | 材质（42CrMo/Cr12MoV…） |

### 8. materials（外购件/物料）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT 🔑 | 物料 ID |
| code | TXT | 编码（GUIDE-PILLAR-40） |
| name | TXT | 名称（导柱/导套/顶杆…） |
| spec | TXT | 规格 |
| unit | TXT | 单位（件/套） |
| source | ENUM | buy（外购） |

### 9. process_routes（工艺路线头）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT 🔑 | 路线 ID |
| product_id | INT | 模具 |
| name | TXT | 路线名 |
| version | INT | 版本 |
| is_active | BOOL | 是否当前有效 |

### 10. process_route_steps（工艺路线明细）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT 🔑 | 步骤 ID |
| route_id | INT | 路线 |
| step_no | INT | 序号（1-6） |
| step_code | TXT | 工序编码（DESIGN/CNC/HT/EDM/FIT/TRY） |
| step_name | TXT | 名称（设计/CNC加工/热处理/EDM/钳工装配/试模） |
| std_hours | DEC | 标准工时（天） |
| station_group | TXT | 可排工位组（如 EDM1-6） |
| review_role | ENUM | 审核人：director（车间主任）/ chief（科长） |

### 11. mold_bom_items（模具部件 BOM · 设计科产出）⭐
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT 🔑 | BOM 项 ID |
| product_id | INT | 模具 |
| part_type | ENUM | make（自制）/ buy（外购） |
| material_id | INT | 外购件（buy 时） |
| steel_spec_id | INT | 铁板规格（make 时） |
| part_name | TXT | 部件名（模架板/型腔镶块…） |
| qty | INT | 数量 |
| drawing_no | TXT | 图纸号 |
| doc_ref | TXT | 设计文件引用 |

### 12. machined_parts（自制件明细）⭐
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT 🔑 | 自制件 ID |
| bom_item_id | INT | 关联 BOM 项 |
| size_class | ENUM | big（大件）/ small（小件）★分组依据（可配置） |
| programming_no | TXT | 编程号（编程科分配） |
| group_id | INT | 所属加工组（外键 machining_groups） |
| status | ENUM | 待加工/加工中/已完成 |

### 13. machining_groups（加工组）⭐
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT 🔑 | 加工组 ID |
| group_no | TXT | 组编号（G-MOLD1001-B） |
| rule_type | ENUM | size（大小）/thickness（厚度）/tool（刀具）← feature flag 可切 |
| tool_spec | TXT | 刀具规格 |
| setup_hours | DEC | 装夹时间（天） |
| per_part_hours | DEC | 单件加工时间（天） |
| total_hours | DEC | 组工时 = 装夹 + 单件×件数（计算值） |

### 14. material_batches（原料批次）⭐
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT 🔑 | 批次 ID |
| steel_spec_id | INT | 铁板规格 |
| batch_no | TXT | 批次号（B-001） |
| qty | DEC | 数量/重量 |
| supplier | TXT | 供应商/炉号 |
| received_at | DATETIME | 入库时间 |
| status | ENUM | in_stock/consumed |

### 15. sn_rules（SN 规则）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT 🔑 | 规则 ID |
| name | TXT | 规则名 |
| prefix | TXT | 前缀（MOLD-） |
| year_flag | BOOL | 是否含年份 |
| serial_digits | INT | 流水位数（4） |
| example | TXT | 示例（MOLD-2025-0001） |

## 五、执行/追溯（5 表）

### 22. work_reports（报工记录）⭐★
| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT 🔑 | 报工 ID |
| work_order_id | INT | 工单 |

| part_id / group_id | INT | 部件/加工组（CNC 粒度） |

| operator_id | INT | 操作工 |
| qty_ok / qty_bad | INT | 合格/不良数量 |
| work_hours | DEC | 工时 |

| review_id | INT | 审核记录外键 |

## 六、追溯链索引（查表路径）

```text
正向：work_order_sns.sn → work_reports（履历）→ batch_bindings → material_batches
反向：material_batches.batch_no → batch_bindings → work_order_sns（受影响模具）
审核：work_reports.status + review_records（谁审/何时/原因）
齐套：mold_bom_items（需求）vs machined_parts.status + purchased_parts_inventory.qty
```
