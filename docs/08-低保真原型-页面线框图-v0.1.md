# MES 演示原型系统 · 低保真原型（页面线框图）

> 版本：v0.1（对应概要设计 §4 页面地图，补图）
> 用途：设计→开发桥梁；每页标注：关键交互 / 角色权限 / 演示要点

## 1. 页面地图总览

```text
登录
├─ 厂长首页：看板 + 交期风险 + 报表
├─ 办公室工作台
│   ├─ 项目科：项目台账 / 模拟排期演示 / 外购件申购
│   ├─ 仓库科：原料批次入库 / 发料 / 外购件库存 / 发货
│   ├─ 计划科：工单管理 / 排产工作台
│   ├─ 设计科：产品 / BOM / 工艺维护
│   ├─ 编程科：加工组细分 / CNC 程序
│   └─ 综合科：（仅角色，无页面）
├─ 车间主任工作台：审核工作台 + 看板
├─ 操作工（工位端）：我的任务 / 开工 / 绑定 / 报工 / 提交 / 安灯
├─ 质量科：看板 + 追溯（只读）
└─ 系统管理：用户 / 角色 / 权限 / 日志 / 一键重置
```

## 2. 核心页面线框

### 2.1 登录页（全部角色）
```text
┌────────────────────────────────────────────┐
│            MES 制造执行系统                  │
│            演示原型 v0.1                     │
│                                            │
│  用户名  [______________________]           │
│  密码    [______________________]           │
│                                            │
│           [      登  录      ]              │
│                                            │
│  演示账号：admin / planner / director /     │
│            op01(op02…) / quality            │
└────────────────────────────────────────────┘
关键交互：登录后按角色跳转对应首页；失败提示
```

### 2.2 工位执行端（操作工 · 核心）
```text
┌────────────────────────────────────────────┐
│ 工位：CNC 1#        操作工：张三   [退出]    │
├────────────────────────────────────────────┤
│ 当前任务：MOLD-1001  CNC粗加工（工序2/6）    │
│ 加工组：大件组（3件）  编程号：P-1001-2      │
│ ┌────────────────────────────────────────┐ │
│ │ ① 扫码开工     [SN 输入框（回车=扫码）]   │ │
│ │ ② 绑定铁板批次 [批次输入框（回车=扫码）]  │ │
│ │ ③ 报工        数量[3]  工时[h]          │ │
│ │ ④ 提交确认 → 状态=待审核                │ │
│ └────────────────────────────────────────┘ │
│ [安灯] 缺料 / 设备 / 质量 / 其他            │
└────────────────────────────────────────────┘
关键交互：3 步闭环（扫码→绑定→报工+提交）；回车模拟扫码；
权限：仅本工位任务；数据范围：自己
```

### 2.3 排产工作台（计划科 / 项目科演示）
```text
┌────────────────────────────────────────────┐
│ 排产工作台          模式：[模拟] [正式]      │
├────────────────────────────────────────────┤
│ 待排工单队列                                │
│ ┌────────┬────────┬────────┬──────────────┐│
│ │工单号   │产品    │交期     │风险          ││

│ │WO-002  │翻边模  │4/05    │✅ 正常        ││
│ └────────┴────────┴────────┴──────────────┘│
│ 建议排期（交期倒排结果）                    │
│ ┌────────────────────────────────────────┐│

```

### 2.4 审核工作台（车间主任 / 各科科长）
```text
┌────────────────────────────────────────────┐
│ 审核工作台（车间主任）  待审核：3 项         │
├────────────────────────────────────────────┤
│ ┌────────┬────────┬────────┬────────┬─────┐│
│ │工单     │工序/环节 │提交人  │提交时间 │操作 ││
│ │WO-001  │CNC组    │张三   │10:32  │[通过]││
│ │WO-001  │钳工装配 │李四   │09:15  │[驳回]││
│ │WO-002  │设计审核 │王工   │08:40  │[通过]││
│ └────────┴────────┴────────┴────────┴─────┘│
│ 驳回弹窗：原因[必填]_____________________    │
│   [确认驳回 → 退回提交人]  [取消]           │
├────────────────────────────────────────────┤
│ 已审核记录（可查：谁/何时/结果/原因）        │
└────────────────────────────────────────────┘
关键交互：通过→流转下一环节；驳回→退回上环节成员附原因，不限次数；
权限：车间主任审厂房全部；科长审本科室
```

## 3. 其余页面（线框从略，功能见设计文档 §4）

| 页面 | 要点 |
|---|---|
| 项目台账 | 项目列表/详情、进度跟踪（项目科维护，其他相关科只读） |
| 外购件申购 | 项目科发起（件/数量/需求日期）→ 仓库科确认到货 |
| 工单列表/详情 | 状态时间线、SN 清单、部件 BOM 查看、交期风险高亮 |
| 主数据 | 产品/BOM/工艺/铁板规格/部件/加工组/批次（查看为主，种子预置） |
| 报表 | 工单进度表（各工序实际 vs 计划、交期达成）、导出 |
| 系统管理 | 用户/角色/权限矩阵/日志/一键重置 |
