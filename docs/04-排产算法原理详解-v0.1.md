> 版本：v0.1（待需求方确认）
> 定位：用大白话 + 演算表格讲清楚"交期驱动倒排排产"算法的每一步，供需求方确认后再编码
> 关联：《SRS v0.2 §4.3》《概要设计 v0.2 §3.1》

---

## 0. 一句话概括

> 系统拿着**承诺交期**，从**最后一道工序**往前推，算出每道工序的"最晚开始 / 结束时间"，同时**避开已经占用的工位**；如果推到头发现"今天开工都赶不上交期"，就明确告诉你**"将延期 X 天"**。你可以手动调整（改开始时间 / 换工位），系统每次调整后**立刻重新计算**，只提示、不强制——**机器建议，人来拍板**。

---

## 1. 算法的输入（排产前要有什么）

| 输入 | 说明 | 例子 |
|---|---|---|
| 工单 | 产品、数量、**承诺交期**（硬约束） | 模具 MOLD-1001，数量 1，交期 3月31日 17:00 |
| 工艺路线 | 每道工序 + **标准工时** + 可排**工位组** | 设计(2d) → CNC粗加工(3d) → 热处理(2d) → EDM精加工(3d) → 装配(2d) → 试模(2d) |
| 工位负载 | 每个工位已有的排产计划（时间占用） | EDM 1# 已被另一套模具占用 3 天 |
| 工作日历 | 哪天上班、每天几小时 | 周一至周六 8:00-17:00（午休 1 小时），周日休息 |

> 关键点：**模具行业每套模具数量=1**，所以工时 = 标准工时 × 1，工序之间**串行**（做完上一道才做下一道）。

---

## 2. 核心思路：为什么"倒排"而不是"正排"？

| 方式 | 做法 | 问题 |
|---|---|---|
| 正排 | 今天开工，往后排，排完看哪天结束 | **交期是客户定的**，正排经常排完才发现超期，只能干着急 |
| **倒排** | 从交期往前推，看每道工序**最晚什么时候必须开始** | 一步到位算出"最晚开工点"，超不超期、超几天**直接可见** |

> 倒排 = "以终为始"：交期是终点，反推每个环节的最晚起点。

## 3. 算法步骤（详细版）

### 3.1 倒排主循环

```text
准备：
  cur_end = 承诺交期（例如 3月31日 17:00）
  工序列表 = [工序1(设计), 工序2(CNC粗), …, 工序6(试模)]，从后往前处理

循环（i = 6 → 1）：
  第 i 道工序：
    ① 工序时长 = 标准工时 × 数量          （模具数量=1，即 2/3/2/3/2/2 天）
    ② 在"可排工位组"里找【最晚可用时间窗】：
        要求：时间在 cur_end 之前、工位空闲、连续时长 ≥ 工序时长
        优先选：结束时间最晚的那段空闲（贪心）
    ③ 该工序 计划结束 = 窗口结束时间
       该工序 计划开始 = 窗口结束时间 − 工序时长
    ④ 留缓冲（可选，默认 0 天）
    ⑤ cur_end = 该工序计划开始 − 缓冲   （继续往前推上一道工序）
```

**直观理解**：试模必须在交期前 2 天开始 → 装配必须在试模前 2 天开始 → EDM 必须在装配前 3 天开始……一路倒推，最后算出**第一道工序（设计）最晚哪天必须开工**。

### 3.2 找"最晚可用时间窗"（负载校验的落地）

```text
对第 i 道工序，在可排工位组（如 EDM 1#-6#）中：
  对每个工位：把该工位已有排期按时间排序，得到它的"空闲时间段列表"
  从中挑选：结束时间最晚、且连续空闲 ≥ 工序时长的窗口
  若多个工位都满足 → 取结束时间最晚的（尽量贴近交期）
  若所有工位都不满足 → 记录"最早可行窗口"（从今天往后找），
      用于计算逾期天数（见 3.3）
```

> 这就是"产能跟不上"的算法化表达：工位全被占满 → 找不到窗口 → 只能顺延 → 逾期。

### 3.3 逾期判定（输出风险等级）

```text
倒排结束后看第一道工序的最晚开始时间：

  最早开始 ≥ 今天 + 2 天      → 风险等级【正常】（从容）
  最早开始 ≤ 今天 + 2 天      → 风险等级【临期】（赶）
  最早开始 < 今天            → 风险等级【逾期】（产能跟不上！）
      预计延期天数 = (今天 − 最早开始) 折算为工作日
      提示："按当前排期将延期 X 天"
```

> "2 天"是**临期阈值**（可配置），用于演示"临期/逾期"两种预警。

### 3.4 手动调整与即时重算（★人的决策权）

```text
计划员可以：
  A. 修改某工序的开始时间（前移 / 后移）
  B. 更换工位（如 EDM 1# → EDM 3#）
  C. 调整缓冲天数

每次调整后，系统【即时重算】并明确提示后果（不禁止）：
  - 冲突检测：调整后是否与同工位其他排期时间重叠 → 提示"与工单 XXX 冲突"
  - 交期重算：新排期下第一道工序最早开始 → 更新风险等级 / 延期天数
  - 若仍无法满足交期 → 计划员可标记"与客户协商中"或确认延期（留痕）
```

### 3.5 模拟排期 vs 正式排期

| | 模拟排期 | 正式排期 |
|---|---|---|
| 用途 | 项目启动会后排方案，线上演示 | 确认后发布执行 |
| 是否占用工位产能 | **不占用**（负载计算忽略模拟单） | **占用** |
| 是否派工 | 不派工 | 派工到工位 |
| 状态 | 草稿 / 模拟 | 已发布 / 已确认 |

> 模拟可以反复调、反复演，满意了才"确认发布"，正式占用产能——避免演示用的方案污染真实排程。

## 4. 演算例子 ①：产能充足（正常通过）

**模具 MOLD-1001 前门内板拉延模**，工艺 6 道工序共 **14 个工作日**，承诺交期 = 第 14 个工作日（以"今天"为第 0 个工作日，交期为第 D 天）。

倒排结果表：

| 工序 | 标准工时 | 可排工位 | 最晚开始 | 最晚结束 |
|---|---|---|---|---|
| ⑥ 试模 | 2d | 试模台 1#-4# | D−2 | **D（交期）** |
| ⑤ 装配 | 2d | 装配 1#-6# | D−4 | D−2 |
| ④ EDM 精加工 | 3d | EDM 1#-6# | D−7 | D−4 |
| ③ 热处理 | 2d | 热处理炉 H1 | D−9 | D−7 |
| ② CNC 粗加工 | 3d | CNC 1#-10# | D−12 | D−9 |
| ① 设计 | 2d | 设计工位 | **D−14（今天）** | D−12 |

**结论**：设计今天开工，恰好交期完成 → 风险=**临期**（无缓冲，刚够）。系统提示"建议留 1-2 天缓冲或提前协调"。

## 5. 演算例子 ②：产能跟不上 → 逾期预警 → 手动调整化解（★核心场景）

**变化**：EDM 1# 已被另一套模具占用第 7-9 天，且 EDM 2#-4# 也有任务，EDM 组在第 7-10 天之间**只剩第 10 天的半天空闲**，不够 3 天。

**倒排结果**：
| 工序 | 原最晚开始 | 调整后 |
|---|---|---|
| ④ EDM 精加工 | D−7 | **最早只能 D−4 开始**（EDM 3# 第 D−4~D−2 空闲） |
| ⑤ 装配 | D−4 | 顺延至 D−2~D |
| ⑥ 试模 | D−2 | 顺延至 D~D+2 |

**系统输出**：
> ⚠️ 逾期预警：按当前排期，试模将顺延到交期后 2 天完成，**预计延期 2 天**（风险=逾期）。

**计划员手动调整**（演示操作）：
1. 把 EDM 精加工**换到 EDM 3#**（负载查询显示其第 D−7~D−5 空闲）→ 系统重算；
2. 重算结果：EDM 回到 D−7 开始，装配/试模恢复原位 → **风险=正常**，提示"调整后可按期完成"。

**调整化解不了时**（例如所有 EDM 都满）：
> 计划员可标记"**与客户协商中**"或确认延期，系统留痕（谁、何时、原因）——对应 SRS 的协商兜底。

## 6. 算法边界与假设（演示版本）

| 项 | 假设 |
|---|---|
| 工作日历 | 周一至周六 8:00-17:00（午休 1h），周日休息；可配置 |
| 工序关系 | 单件串行（一套模具逐工序），暂不支持并行拆分 |
| 工时 | 按标准工时定额；复杂模具系数暂不启用 |
| 缓冲 | 默认 0，可配置（演示建议 0.5-1 天） |
| 工位 | 每道工序指定"可排工位组"，组内任选 |
| 冲突规则 | 同一工位时间重叠即冲突；跨工位不冲突 |
